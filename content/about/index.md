I build production-grade AI systems — from retrieval-augmented generation pipelines to autonomous agentic workflows — backed by a decade of full-stack engineering experience designing high-performance web applications.

### 🤖 AI/ML Engineering

- **RAG Pipelines:** LangChain, ChromaDB, advanced retrieval strategies including query decomposition, HyDE, step-back prompting, and multimodal RAG
- **Agentic Systems:** LangGraph, TypedDict/Pydantic state schemas, multi-agent orchestration, summarization middleware, and human-in-the-loop workflows
- **Model Context Protocol (MCP):** Building MCP-based tools for standardized LLM-to-system interoperability, separate from native LangChain tool definitions
- **Structured Output & Reliability:** Pydantic-enforced outputs, `with_structured_output()`, and schema validation for production reliability
- **LLM Integration:** OpenAI, Anthropic APIs, prompt engineering, and vector search optimization

As a passionate AI and web architect, I design systems that combine reliable retrieval, structured reasoning, and production-ready engineering — moving beyond prototypes toward scalable, maintainable architectures.
